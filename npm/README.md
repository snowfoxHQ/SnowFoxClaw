# snowfoxclaw

Personal AI agent — a fox living in your device.

> **0.1.0 is a placeholder release.** This package currently only reserves the
> `snowfoxclaw` name on npm. The actual agent will be shipped in a later version.

## Install

```bash
npm install snowfoxclaw
```

## Usage

```js
import { version } from "snowfoxclaw";

console.log(version); // 0.1.0
```
