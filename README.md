# SnowFoxClaw

个人 Agent 智能体，住在你设备里的狐狸。

> **0.1.0 是占位版本。** 当前仅用于在 PyPI 上保留 `snowfoxclaw` 包名，功能尚未实现。

## 安装

```bash
pip install snowfoxclaw
```

## 验证

```bash
python -c "import snowfoxclaw; print(snowfoxclaw.__version__)"
foxclaw --version
```

## 开发

```bash
git clone https://github.com/snowfoxHQ/SnowFoxClaw
cd SnowFoxClaw
pip install -e .
python -m build
```
